Page 1 : Dashboard / Accueil

URL : /dashboard ou /

Objectif
Fournir une vue synthétique de l'état global de conformité. Page d'accueil qui affiche les KPI principaux, les alertes critiques, et permet de naviguer rapidement vers les 3 autres pages.
Structure de la mise en page (Layout)
En-tête : Logo, titre "Suivi de Conformité ISO 27001 / NIS2-ANSSI", date de dernière mise à jour

Barre de navigation : 4 boutons/liens : Tableau de bord, Lacunes, Détail, Roadmap (ou menu hamburger mobile)

Zone principale : Grille de KPI (4 cartes) + Bloc alertes critiques + Graphique de progression simplifiée

Pied de page : Dernière synchronisation, version, lien aide
Composants clés
🎯 4 Cartes KPI
Score global (%) | Lacunes identifiées (nb) | Implémentations en cours (nb) | Domaines conformes (nb/14)
Essentiel
📊 Graphique de progression
Donut chart simple montrant % de conformité global + 3-4 barres de domaines majeurs
Essentiel
⚠️ Bloc "Alertes prioritaires"
Liste 3-5 lacunes critiques ou implémentations en retard, avec badges rouge/orange
Essentiel
🚀 Bloc "Actions rapides"
Boutons : Nouvelle lacune, Voir roadmap, Afficher toutes lacunes, Exporter rapport
Essentiel
Éléments interactifs
  • Cliquer sur une KPI → Navigue vers Page 2 (Lacunes) avec filtres appliqués
  • Cliquer sur une alerte → Navigue vers Page 3 (Détail lacune)
  • Bouton "Nouvelle lacune" → Ouvre modale de création (ou redirige Page 2)
  • Bouton "Voir roadmap" → Navigue vers Page 4
  • Menu navigation → Bascule entre les 4 pages principales
Navigation
Arrivée : Page par défaut (/), lien "Accueil" depuis autres pages
Sortie : Menu nav (Lacunes → Page 2) | Alerte (Détail → Page 3) | Roadmap (→ Page 4)
Contenu
  • Titre : "Tableau de bord - Conformité ISO 27001 / NIS2-ANSSI"
  • Sous-titre : "Dernière mise à jour : 24/09/2026 14:32"
  • KPI 1 : "Score global : 45%"
  • KPI 2 : "Lacunes identifiées : 23"
  • KPI 3 : "Implémentations en cours : 8"
  • KPI 4 : "Domaines conformes : 2/14"
  • Alertes exemples : "🔴 MFA non configurée - Criticité haute" | "🟠 Sauvegardes non testées"
États de la page
État Affichage
Loading Skeleton des KPI et graphiques, spinner
Première utilisation Message : "Commencez par créer un audit initial" + Bouton "Nouvelle lacune"
Données chargées Dashboard complet avec KPI, graphiques, alertes
Erreur chargement Banneau rouge : "Erreur de connexion. Veuillez réessayer" + Bouton retry

Page 2 : Inventaire des lacunes

URL : /gaps ou /lacunes

Objectif
Afficher la liste complète des lacunes identifiées. Permettre filtrage, recherche, tri, création, et accès rapide au détail de chaque lacune.
Structure de la mise en page (Layout)
En-tête : Titre "Inventaire des lacunes", compteur total, score global

Barre d'outils : Champ recherche (full-text) + Filtres dropdown (Criticité, Domaine, Statut) + Bouton "Nouvelle lacune"

Zone de contenu : Tableau affichant : ID | Titre | Domaine | Criticité (badge) | Statut | Créé | Actions

Pagination : 20 lacunes par page
Composants clés
🔍 Barre de recherche
Recherche full-text. Placeholder : "Chercher une lacune (MFA, chiffrement, etc.)"
Essentiel
📌 Filtres (3 dropdowns)
Criticité (Critique/Haute/Moyenne/Basse) | Domaine (9 domaines ISO) | Statut (Non traitée/En cours/Corrigée/Validée)
Essentiel
📋 Tableau des lacunes
Colonnes : ID | Titre | Domaine | Criticité (badge couleur) | Statut | Date création | Menu (...)
Essentiel
➕ Bouton "Nouvelle lacune"
Ouvre une modale ou navigue vers Page 3 en mode création
Essentiel
Éléments interactifs
  • Taper dans recherche → Filtre en temps réel la liste
  • Cliquer filtre → Applique le filtre, met à jour le compteur
  • Cliquer sur une lacune (titre) → Navigue vers Page 3 (Détail)
  • Cliquer en-tête colonne (Titre, Domaine, etc.) → Tri ascendant/descendant
  • Menu "..." sur lacune → Options : Dupliquer, Archiver, Supprimer
  • Pagination → Naviguer entre pages
Navigation
Arrivée : Menu nav "Lacunes", Dashboard (clic KPI)
Sortie : Clic lacune → Page 3, Menu nav → autres pages
Contenu
  • Titre : "Inventaire des lacunes"
  • Compteur : "23 lacunes | Critiques: 5 | Hautes: 8 | Moyennes: 7 | Basses: 3"
  • Exemples de titres :
    • GAP-001: "MFA non configurée sur portail admin"
    • GAP-002: "Chiffrement données non activé en transit"
    • GAP-003: "Pas de plan de sauvegarde testé"
  • Badges statut : "Critique" (rouge) | "Haute" (orange) | "Moyenne" (jaune) | "Basse" (bleu)
États de la page
État Affichage
Loading Skeleton du tableau
Aucune lacune Message : "Aucune lacune trouvée. Créer la première →" + Bouton "Nouvelle lacune"
Filtre aucun résultat Message : "Aucune lacune ne correspond aux filtres"
Données chargées Tableau complet avec pagination

Page 3 : Détail d'une lacune

URL : /gaps/:id ou /lacunes/:id

Objectif
Afficher tous les détails d'une lacune, permettre son édition, associer des implémentations, et suivre la preuve de conformité / résolution.
Structure de la mise en page (Layout)
En-tête : Titre lacune, ID, badges (criticité, statut)

Zone gauche (70%) : Onglets | Détails | Implémentations | Preuve & Validation

Panneau droit (30%) : Métadonnées (Créé par, Domaine, Assigné à), boutons Actions (Éditer, Dupliquer, Archiver)

Contenu principal : Formulaire/affichage selon onglet actif
Composants clés
📋 Onglet "Détails"
Affichage/édition : Titre | Description | Domaine ISO | Criticité | Statut | Règle NIS2/ANSSI | Impact potentiel | Délai résolution
Essentiel
🔗 Onglet "Implémentations"
Liste des actions pour corriger lacune. Chaque implémentation : Titre | Statut | % Avancement | Date cible | Lien vers Page 4
Essentiel
✅ Onglet "Preuve & Validation"
Upload/lien vers documents prouvant la conformité : Screenshot | Certificat | Rapport audit | Signature responsable
Essentiel
📝 Bouton "Éditer"
Permet éditer champs en modal ou in-place. Buttons: Sauvegarder, Annuler
Important
📄 Panneau métadonnées
Créé par | Date création | Assigné à | Dernier modifié par | Date modif
Important
Éléments interactifs
  • Bouton "Éditer" → Ouvre formulaire édition en modal ou in-place
  • Cliquer onglet → Bascule entre Détails, Implémentations, Preuve
  • Cliquer implémentation → Navigue vers Page 4 ou affiche inline
  • Bouton "Ajouter implémentation" → Ouvre formulaire création lié à cette lacune
  • Upload fichier preuve → Ajoute pièce jointe avec date/uploader
  • Change statut (dropdown) → Sauvegarde automatiquement
  • Bouton "Dupliquer" → Crée copie de la lacune
  • Bouton "Archiver" → Soft delete (marque archivée)
Navigation
Arrivée : Clic lacune depuis Page 2, ou lien direct /gaps/GAP-001
Sortie : Bouton "Retour" → Page 2, Implémentation → Page 4
Contenu
  • Titre : "GAP-001 : MFA non configurée sur portail admin"
  • Description : "Le portail d'administration ne dispose pas d'authentification multi-facteurs, exposant les comptes admins aux attaques de phishing."
  • Domaine : "Gestion des accès (A.9)"
  • Criticité : "Critique"
  • Statut : "En cours"
  • Règle : "NIS2 Article 20, ANSSI - Mesure 1.1"
  • Impact : "Accès non autorisé aux données sensibles, compromission infrastructure"
  • Délai cible : "30 jours"
États de la page
État Affichage
Loading Skeleton du formulaire
404 Message : "Lacune non trouvée" + lien retour Page 2
En édition Champs modifiables, boutons Sauvegarder/Annuler visibles
Sauvegarde réussie Toast vert : "Lacune mise à jour"
Erreur sauvegarde Toast rouge : "Erreur sauvegarde" + Bouton retry

Page 4 : Roadmap de conformité

URL : /roadmap ou /planification

Objectif
Afficher un plan d'action hiérarchisé montrant les implémentations à mettre en place pour corriger les lacunes, avec priorités, délais et statut de progression.
Structure de la mise en page (Layout)
En-tête : "Roadmap de conformité", période (ex: Q1 2025 → Q4 2025)

Barre d'outils : Bouton "Vue Gantt / Kanban", filtres (Criticité, Domaine), sélecteur période

Vue Gantt (défaut) : Timeline horizontale montrant implémentations avec dates cibles, jalons

Vue Kanban (alt.) : Colonnes (À faire | En cours | Bloqué | Validé) avec cartes des implémentations

Légende : Couleurs par statut et criticité
Composants clés
📊 Timeline Gantt
Graphique temporel : Implémentation | Barre durée (colorée par statut) | Date début/fin | % Avancement. Cliquer pour détails
Essentiel
📅 Jalons (Milestones)
Marqueurs de dates importantes : Fin Q1 (30% conformité) | Fin Q2 (60%) | Fin Q3 (100%)
Important
📈 Vue Kanban (alternative)
4 colonnes : À faire | En cours | Bloqué | Validé. Cartes drag-drop avec titre, criticité, date cible
Important
🎯 Indicateurs de criticité
Couleurs barres : Rouge (Critique) | Orange (Haute) | Jaune (Moyenne) | Bleu (Basse)
Important
Éléments interactifs
  • Cliquer barre Gantt → Affiche détails implémentation
  • Glisser barre Gantt → Modifie date cible (inline edit)
  • Cliquer en-tête colonne Gantt → Change sens tri (date)
  • Bouton "Vue Gantt/Kanban" → Bascule entre représentations
  • Drag-drop en Kanban → Change statut implémentation
  • Filtrer par criticité → Cache/affiche tâches correspondantes
  • Sélectionner période → Recharge roadmap pour plage sélectionnée
Navigation
Arrivée : Menu nav "Roadmap", Dashboard (bouton "Voir roadmap")
Sortie : Clic implémentation → Détails (dans Page 3 ou modal) | Menu nav → autres pages
Contenu
  • Titre : "Roadmap de conformité ISO 27001 / NIS2-ANSSI"
  • Sous-titre : "Plan d'action : Janvier 2025 → Décembre 2025"
  • Jalons visibles :
    • "Fin Q1 (31/03) : 30% conformité"
    • "Fin Q2 (30/06) : 60% conformité"
    • "Fin Q3 (30/09) : 100% conformité"
  • Implémentations exemples :
    • IMP-001: "Déployer Vault" (Crypto | Q1) ████░ 60%
    • IMP-002: "Activer MFA" (Accès | Q1) ███░░ 50%
    • IMP-003: "Audit SIEM" (Ops | Q2) ░░░░░ 0%
États de la page
État Affichage
Loading Skeleton Gantt chart
Aucune implémentation Message : "Aucune implémentation planifiée. Créer la première depuis Page 3"
Roadmap chargée Timeline Gantt complète avec jalons et implémentations
En retard (alert) Tâche surlignée rouge si date cible < aujourd'hui
