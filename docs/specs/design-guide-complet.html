Poids de Police

  • 400 (Regular) - Corps, paragraphes, descriptions
  • 500 (Medium) - Labels, labels de formulaire, petit texte important
  • 600 (Semibold) - Titres h3, boutons, accents
  • 700 (Bold) - Titres h1/h2, emphasis forte

Hauteurs de Ligne (Line Height)

  • 1.2 - Titres courts (h1)
  • 1.3 - Titres (h2)
  • 1.4 - Petits titres (h3), labels
  • 1.5 - Texte secondaire, petit texte
  • 1.6 - Corps principal (lisibilité optimale)

Lettrage (Letter Spacing)

  • -0.02em - H1 (rapprochement pour densité)
  • -0.01em - H2 (léger rapprochement)
  • 0em (normal) - Corps, h3
  • 0.05em - Labels, badges, petit texte majuscule
  • 0.1em - Labels formulaire, muy petit texte
